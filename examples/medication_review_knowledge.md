# 合成知识资料：用药安全复核与信息补全

> 用途：医疗 Agent 功能测试资料。所有内容均为合成的流程性信息，不构成针对任何个体的医疗建议。

## 1. 处方前与用药复核信息

开展用药安全复核时，应建立当前用药清单，并核对药物名称、使用方式、近期新增或停用情况、药物过敏或不良反应史、既往疾病、肝肾功能、近期检查结果及潜在相互作用。信息缺失时，应将缺失项标记为待补充，而不是推断具体处置。

## 2. 肾功能与高风险人群信息

当病历提示肾功能异常、老年、多重用药或近期出现新的不适时，复核人员应确认检查时间、趋势、完整用药清单、非处方药及保健品使用情况，并由具备资质的临床专业人员结合完整信息判断后续处置。

## 3. 风险升级边界

若出现进行性呼吸困难、持续胸痛、意识改变、活动性出血、严重过敏反应或其他急性加重风险信号，应优先寻求紧急医疗评估。自动化系统只能提示需要进一步评估，不能替代急诊分诊、诊断或处方。

## 4. 证据与沟通要求

患者特异性结论应同时引用患者病历事实和适用的知识库依据。每条结论需要明确其证据来源；当证据不足、检查时间不明或资料相互矛盾时，应说明不确定性并建议人工复核。
